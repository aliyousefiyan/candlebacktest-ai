۲. بررسی قوانین قبل از اجرا

اگر AI سؤال یا فرض اضافی پیشنهاد کرد، قبل از اجرا مشخصات را خودت اصلاح و تأیید کن. هیچ Python یا Pine از این قسمت اجرا نمی‌شود.

راه ساده بدون کدنویسی: استراتژی تقاطع میانگین متحرک

اگر هوش مصنوعی محلی نداری، همین چند گزینه را انتخاب کن؛ برنامه قوانین JSON را به‌طور خودکار ایجاد می‌کند. این فرم فعلاً فقط استراتژی تقاطع SMA/EMA را می‌سازد.
