# Security and privacy

This demo binds the browser interface only to 127.0.0.1. It is NOT a production internet-facing server and has no authentication or rate limiting. Never expose it through public port forwarding. Do not upload exchange credentials, real account logs, protected Pine scripts or private trading research to a public repository. Report bugs privately to the maintainer through an appropriate GitHub contact channel without including secrets. The local AI request uses the Ollama loopback endpoint; no external model endpoint is configured.
